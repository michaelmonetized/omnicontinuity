# OmniContinuity

Complete full featured continuity and handoff with Airdrop, Airplay, Camera, Clipboard, Mirroring, Nearby, Sidecar, etc. support across Arch Linux, macOS, Android, iOS, iPadOS, and TVOS.

## Additional Features:

- Automount LAN and Tailscale accessible machine disks.
- Automount discovered ~/Library/Mobile Documents folders in ~/Cloud/<hostname>/<user>/

Leverages existing codebases such as lan-mouse, ssh-clipboard, omdrop, omarchy iphone mirror, etc. (discovery pending).
